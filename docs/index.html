Install Chezzflix

A fast, TV-first way to watch your Plex library. Pick your device below. After the first install, the app keeps itself up to date.

Fire TV, Shield, Onn & Android TV

Works from anywhere. You don't need to be on the same network as the Plex server.
  1. On the TV, install the free Downloader app (Amazon Appstore on Fire TV, Google Play on Shield/Onn/Android TV).
  2. Allow it to install apps: Settings → Apps / Security → Install unknown apps → Downloader → On (Fire TV: Settings → My Fire TV → Developer options → Install unknown apps).
  3. Open Downloader and type this address, then choose Go:
    github.com/ChezzterGReed/chezzflixapp/releases/latest/download/Chezzflix.apk
  4. When it finishes, choose Install, then Open.
  5. Sign in: the TV shows a short code. On your phone or computer go to plex.tv/link and enter it.

First time asking someone to do this? Send them this page. Typing is easiest with the Downloader app's on-screen keyboard or a phone remote app.
